# 데이터 표준화 및 AI Ready Data 구축 전략 — 실습 폴더 (1~5일차)

## 0. 폴더 놓는 위치

압축을 풀고 **폴더 이름을 `dstd` 로 바꿔 `C:\` 바로 아래**에 두십시오. 최종 경로는 이렇게 됩니다.

    C:\dstd

한글·공백·OneDrive 가 들어간 경로에 두면 명령이 길어지고 오류가 잦습니다. 바탕화면·문서 폴더는 피하십시오.

## 1. 처음 한 번 (1일차 2~3교시)

PowerShell 을 열고 한 줄씩 칩니다.

    cd C:\dstd
    py -m venv .venv
    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt

`activate` 는 쓰지 않습니다. 항상 `.\.venv\Scripts\python.exe` 를 직접 부릅니다.

## 2. 원천 데이터 만들기 (1일차 6교시)

    .\.venv\Scripts\python.exe src\make_dataset.py --variant common --size sample --out data\sample --no-answer
    .\.venv\Scripts\python.exe src\make_dataset.py --variant common --size full  --out data\raw\common --no-answer

데이터는 **여러분이 직접 만듭니다.** 같은 명령을 다시 돌리면 같은 파일이 나옵니다.

## 3. 매일 아침 (2일차부터)

    cd C:\dstd
    .\.venv\Scripts\python.exe src\check_env.py

`[실패]` 가 있으면 바로 아래 `→` 줄의 명령을 그대로 실행하고 다시 진단합니다.

## 4. 폴더 안내

| 폴더 | 무엇이 들어 있나 |
|---|---|
| `src\` | 실행하는 파이썬 파일 (생성기·검사기·도우미) |
| `notebooks\` | 일차별 실습 노트북. `# %%` 가 셀 구분선, `Shift+Enter` 로 실행 |
| `templates\` | 사전·매핑표·규칙 정의서·모델·DDL 템플릿. **복사해서** 쓰고 원본은 남겨 둡니다 |
| `sql\` | Workbench 에서 여는 SQL 파일 (4~5일차) |
| `docs\` | 업무설명서·원천데이터 정의서. **내가 만든 산출물도 여기에 저장**합니다 |
| `data\` | 원천 데이터와 작업 결과. 2번을 돌리면 생깁니다 |

## 5. 산출물 이름 (검사기가 이 이름으로 찾습니다)

| 파일 | 언제 |
|---|---|
| `docs\표준사전.xlsx` | 2일차 |
| `docs\매핑표.xlsx` | 2일차 |
| `docs\변환규칙정의서.xlsx` | 3일차 |
| `docs\AS-IS품질보고서.md` | 3일차 |
| `docs\모델_ASIS.md` · `docs\모델_TOBE.md` | 4일차 |
| `docs\ddl.sql` | 5일차 |

이름이 다르면 검사기가 "파일이 없습니다" 라고 합니다. 내려받은 파일 이름을 꼭 바꾸십시오.

## 6. 검사기 한눈에

    .\.venv\Scripts\python.exe src\check_env.py                        환경 진단 (매일)
    .\.venv\Scripts\python.exe src\check_dictionary.py                 표준 사전 (2일차)
    .\.venv\Scripts\python.exe src\check_rulebook.py                   변환 규칙 정의서 (3일차)
    .\.venv\Scripts\python.exe src\check_model.py                      TO-BE 모델 (4일차)
    .\.venv\Scripts\python.exe src\check_model.py --asis               AS-IS 모델 (4일차)
    .\.venv\Scripts\python.exe src\check_ddl.py                        DDL (5일차)
    .\.venv\Scripts\python.exe src\check_mysql.py                      실습 DB 접속 (4일차부터)

## 7. 자주 막히는 곳

- **`ModuleNotFoundError: pandas`** — 1번을 건너뛴 것입니다. `pip install -r requirements.txt`
- **커널을 `.venv` 로 골랐는데도 같은 오류** — 커널 선택과 패키지 설치는 다른 일입니다. 위 명령을 다시.
- **`NameError: ROOT`** — 노트북 셀을 건너뛰었거나 커널을 재시작한 것입니다. 셀 1부터, 또는 `Run Above`.
- **F5(디버그)로 실행** — 쓰지 마십시오. 셀 실행은 `Shift+Enter` 하나로 통일합니다.
- **원천 파일을 엑셀로 열지 마십시오** — 저장하는 순간 `0000123` 이 `123` 이 됩니다.
